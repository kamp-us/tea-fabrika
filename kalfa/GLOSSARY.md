# Shared names

The few words every kalfa context uses with one meaning.

## Language

**Stream**:
An ordered sequence of values; a context may name one and keep it, as the ledger does.
_Avoid_: feed, flow, sequence

**Platform**:
The kind of runtime a program runs on, such as Node, a browser or a Durable Object.
_Avoid_: environment, place, host, target

**Replica**:
One copy of a ledger, kept where it is used: on a device, in a browser tab or in the cloud.
_Avoid_: place, copy, mirror, node

**Tag**:
What kind of value something is: one name out of a fixed set, carried on the value itself, so a
reader can match on it or pick values by it.
_Avoid_: type, kind (as the field), discriminator
