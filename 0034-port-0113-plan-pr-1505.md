## Details

- **`stepcommit` (S12)** now takes `plan` as a step. Its law: `--commit-only plan` commits the
  named paths, and a signed `plan` commit refuses with its own line and exit 2, since no plan step
  key exists yet. The refusal half is the plan's lean, at 80%.
- **Services.** Three are new: `Git`, `Lock` (taken from the pid-file lock already in
  `flow/host.ts`) and `Env`. Already in the repo and reused: the process runner in `pr/command.ts`,
  `PullRequests`, the `box/Runs` service, and Effect's own `FileSystem`, `Clock` and `TestClock`.
- **The lint check** is a step in `pnpm lint`, not an oxlint rule, because oxlint never reads
  `.sh` files.
  - Its list of scripts not yet ported lives in the check's own source, an exam path, so no build
    step can edit it.
  - A law holds the list to the files the plan names, and an entry for a gone file fails lint.
  - `scripts/typecheck.sh` stays on the list until `fabrikalfa/port-typecheck` lands. The list is
    deleted when it is empty.
  - `apt.sh` is not on the list; it carries its own `edge:` line, the form 0524 keeps.
- **Tests.** Every old test keeps its exact title. A small set that runs real git becomes
  `.integration.` tests.
- **Size.** About 3,380 lines (70% sure), in about 57 steps, for about $100.
