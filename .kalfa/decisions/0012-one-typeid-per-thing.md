# Every thing has one TypeID

Every thing gets one id, `<type>_<suffix>` with a UUIDv7 suffix (the TypeID format), as a branded schema so one type's id cannot pass for another's. Data points only at the id, never at a number or a title; ids are stable and given by code, never by an agent. A counted thing also has a number, but only the program that owns it prints and parses it (`#193`).
