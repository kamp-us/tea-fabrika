# Every permission is one ReBAC system on Zanzibar's model

Every permission question (people, agents, keys, programs, packs) is answered by one relation system: `(subject, relation, object)` rows on the ledger, one model declared once, and a typed check that gives a sealed proof a step cannot compile without. It replaces four separate lists. Rows live on the ledger and the check runs in the brain, so there is no outside permission server (SpiceDB, OpenFGA); limits like spend and CPU are walls, not permissions.
