# Agents commit as a bot, with the person as co-author

An agent's commit is authored by a GitHub App's bot, with the person in a `Co-authored-by` trailer, so GitHub shows a person's work apart from an agent's. One bot serves all of one owner's projects, with its one key in the brain's secrets store. Only main's squash commit carries GitHub's Verified badge.

## Considered Options

A machine user: rejected, because it needs a second GitHub account per person.
