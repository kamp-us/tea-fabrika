# Each client signs in with its own key, granted by a person key

Every client (browser tab, app window, agent bridge) signs in with its own key, granted by a person key in SSHSIG's shape, and a revoke is one event. Every device a person owns holds an equal person key, as on Apple and Keybase, and an agent never does. A key is never let in because GitHub lists it for a login: who may be in a fabrika is that fabrika's own fact.
