# A summoned agent holds no key, and the brain stamps its writes

A summoned agent is a program the brain runs, and its turns run on hands (0044), so the brain already knows which agent made each write and stamps it with the agent's name and the human it acts for, the way a kernel stamps a process with its owner. Only an agent that dials in on its own, such as a person's own harness session, holds a key, granted as 0022 says. Identity records an agent by its name, unique among its human's agents, and the human it acts for; a key is optional.

## Considered Options

- Making a key in Secrets at every summon and signing the agent in with it: rejected, because a key the brain holds for itself proves nothing the brain does not already know, and an agent's box never holds our keys (0027).

## Consequences

Nothing can check a signature on a summoned agent's writes; the brain's stamp is the record. Those writes are still the agent's own, never its human's (0026).
