# Programs run in the brain, and a machine's work goes to a hands client

A program's process runs in the brain, and the brain is workerd everywhere, the laptop included; Node runs only the hands. All machine work (files, git, Docker, agents, keys, the terminal) is a Cmd the hands do: a program never touches a computer, it asks, and the hands answer with a Msg, so every step stays a message and every process can be watched and replayed. Each set of hands says what it `has` and a Cmd says what it `needs`; a capability says what a client can do, never what it may do, and that is decided on the ledger.

## Consequences

The hands always connect to the brain, never the reverse, because a Worker cannot connect to a laptop. A browser tab keeps its own `has` list, and a Cmd that `needs` git never goes to it: a tab can't run a process, so it never says it has one, and the queue never offers it that task.
