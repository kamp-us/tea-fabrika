# Programs run in the brain, and a machine's work goes to a hands client

Every program runs in the brain, on workerd, in every place. A command that needs a machine goes as a job to a hands client whose capabilities cover it. A capability says what a client can do, never what it may do: that is a permission.

## Consequences

A browser tab can be a hands client, but only for jobs its capabilities cover; a job that needs a shell goes to a machine that has one.
