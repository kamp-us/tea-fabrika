# We build our own tools first, and each view is its own program

When the team needs a tool, the first answer is a program on the ledger, and a program that feels worse than the tool it replaces is a bug to fix, not a reason to go back. The tracker's ticket page, board and list are separate programs that share only the ledger and one fold. The cost is that each folds the whole ledger: fine for hundreds of tickets, not for tens of thousands.
