# Guidelines

One page per design area: the area's principles together, read whole, and edited in place when a
guideline changes ([0136](../../.decisions/0136-guidelines-live-in-their-own-pages.md)). A text area
is `<area>.md`; a visual area is a folder, `<area>/README.md`, with real shots from the built app in
`<area>/shots/`. The guidelines skill writes them ([its steps](../../.claude/skills/guidelines/SKILL.md)).

Each page says its status on its first line: **Proposed DATE.** with a link to its experiment, or
**Approved DATE.** with a link to the approval decision. This folder keeps no index table
([0522](../../.decisions/0522-no-folder-keeps-an-index-table.md)): list it to see the areas.
